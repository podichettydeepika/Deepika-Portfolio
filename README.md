# Deepika Podichetty — Portfolio

Professional portfolio for Deepika Podichetty, AI/ML Engineer, Generative AI Engineer and Associate Forward Deployed Engineer.

## Run locally
Open `index.html` directly in a browser, or use VS Code Live Server.

## GitHub Pages
1. Create a public repository named `deepika-portfolio` under `podichettydeepika`.
2. Upload all files from this folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/(root)`, then **Save**.
6. The expected project-site address will be `https://podichettydeepika.github.io/deepika-portfolio/` after GitHub finishes deployment.

## Vercel
Import the same GitHub repository into Vercel. Because this is a static site, no build command is required.

## Before publishing
Review employer/project descriptions for any company-confidential information. Replace or remove any content Deepika does not want public.
